# Enough

> 你的决定，本来就已经够好了。

一个**日常决策伴侣**。给纠结设预算，到点就提交；三天后回头验证「你担心的事到底发生没有」。

- 📦 发布产物 **52.7 KB**（gzip ~17.9 KB）
- 🧩 运行时依赖 **2 个**（Preact + htm）
- 🔒 零服务端 · 零账号 · 数据只存在本机
- 🚫 非医疗工具，不替代诊断与治疗

---

## 快速开始

### 只想试试看

```bash

npm run build
npm run serve
```

构建后 `dist/index.html` 是一个自包含页面，**双击即可运行**，也可以直接发给别人（微信、邮件都行）。

## 功能

| 视图 | 说明 |
|---|---|
| **今天** | 真实统计 · **摇一签**（今天做什么 / 吃什么 / 玩什么）· 决策与快判入口 · 待回访提醒 |
| **规划** | 小规划（每日/每周，**强制只填 3 件**）· 大规划（**不打勾**，只关联「围绕它做过的决定」）|
| **账本** | 两下点击记账，6 类占比统计 |
| **复盘** | 周 / 月 / 年报：决定数 · 纠结时长 · **担忧成真率** · 消费结构 · 高频纠结时刻 · **可导出分享图** |
| **我的** | 本机存储声明 · 导出 JSON · 清空 |

### 三个账本

```
决策账本 ── 我做了什么选择，担心的成真了吗
时间账本 ── 我把时间花在哪了
金钱账本 ── 钱花在哪了
        ↓
   报表 = 三个账本的对账
```

## 设计原则

这个产品服务于「纠结」和「强迫」倾向的人，因此有几条**强制规则**：

- ❌ 无排行榜、无对比他人（对比本身就是焦虑源）
- ❌ 无连续打卡天数、无进度环
- ❌ 无「完成！」弹跳动画（完成只给一次静态反馈）
- ✅ 每天最多 1 次主动提醒
- ✅ 漏记完全无感，不补、不惩罚
- ✅ 所有数字来自真实记录，**零硬编码假数据**
- ✅ 摇签**摇完即忘**，不进日志、不计数——避免变成新的强迫仪式

## 技术

```
src/
  model.js     数据层 + 聚合引擎（决策/账本/报表统计）
  views.js     9 个视图
  share.js     年度分享卡（Canvas，零依赖）
  ui.js        UI 组件库
  state.js     hash 路由 + 全局状态
  styles.css   设计 token + 全部样式（~120 行）
  app.js       外壳与路由
```

- **零框架级依赖**：Preact（4KB 级替代 React）+ htm（无构建 JSX）
- **Hash 路由**：任何视图都可分享：`#/plan/big`、`#/review/year`
- **数据**：localStorage，页面隐藏/关闭时立即落盘
- **构建**：esbuild 单文件打包，~200ms

## 数据与隐私

- 不联网、不需要账号、不上传任何数据
- 全部记录存于浏览器 localStorage
- 可随时导出 JSON，可随时清空
- 清空浏览器数据即彻底删除
